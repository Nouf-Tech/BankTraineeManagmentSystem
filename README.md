نظام سطح مكتب تجريبي متكامل ومنفصل عن النظام الأساسي تم تطويرة كمشروع تخرج لبيئات العمل البنكية/الشركات لأتمتة توزيع المهام اليومية بين المتدرب والموظف لإدارة بيانات العملاء مع تطبيق نظام صلاحيات مبني على Roles وتحديد أولويات العمل 
فكرة النظام : عبارة عن ثلاث واجهات 
الواجهة الأولى LoginForm : تم تصميمها للتحقق من هوية المستخدم وتوجيهه حسب صلاحيته (موظف أم متدرب)
الواجهة الثانية EmployeeForm : يمكن للموظف الإطلاع على كافة بيانات العملاء, ويمكنه إضافة عملاء جدد دون الحاجة للدخول الى قاعدة البيانات الأصلية في SSMS ويمكنه توزيع المهام للمتدربين مع إمكانية إرفاق ملاحظة وتحديد مستوى أولوية المهمة (Low, Medium, High)
الواجهة الثالثة TraineeForm : يمكن للمتدرب الإطلاع على بيانات مخصصه وقائمة مقتصره على العملاء المرتبطين بالمهام المسندة إليه فقط. لزيادة ضمان سرية معلومات العميل دون الحاجة لدخول المتدرب الى نظام الشركة/البنك الأساسي 
الميزات الأساسية : 
إدارة بيانات العملاء وتنفيذ كافة عمليات CRUD (إضافة, إستعلام, تعديل, حذف) 
نظام منح الصلاحيات وتوزيع المهام مع تحديد الأولويات 
الربط الآمن والمباشر مع قاعدة البيانات واستعلامها عبر ADO.NET 
التقنيات المستخدمة : 
Language : C# 
IDE : Microsoft Visual Studio 2022 
DataBase Management : SQL Server Management System / (localdb)
FrameWork : .NET Frame Work - Windows Form (WinForm)
